# Inventory — LED UNION

> Generated by Reversa Scout · 2026-10-24 · confidence: 🟢 CONFIRMED unless noted

## Summary
- **What:** PWA that controls Bluetooth LE LED controllers from several vendor-app families (Magic Lantern, Lotus Lantern, LED+LAMP, BLEDIM) via Web Bluetooth. Multi-device / group control. No backend, no account.
- **Primary language:** TypeScript (Svelte 5 runes)
- **Framework:** Svelte 5.57 + Vite 8 + vite-plugin-pwa
- **Version:** 0.1.0 (`package.json`)
- **Tracked source:** ~6k LOC (src + tools)
- **Deploy:** GitHub Pages under `/LED_UNION/` (HTTPS required by Web Bluetooth)
